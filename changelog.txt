2. DIRECT FILE-BY-FILE COMPARISON (OLD vs NEW)
================================================================================

--------------------------------------------------------------------------------
A) reforge/bake.py
--------------------------------------------------------------------------------
OLD (defold-export-for-blender-main):
- Did NOT exist.
- Materials were limited strictly to static image textures directly plugged into
  the "Base Color" socket of Principled BSDF.
- Complex shaders, Ucupaint layers, procedural textures (Noise, Voronoi, ColorRamp),
  and Vertex Colors could NOT be exported to Defold.

NEW (Current):
- Fully featured 475-line baking pipeline (`bake_color_emit_png`).
- Traverses complex shader node graphs, linking color sources into an unlit
  Cycles Emission node for pure albedo extraction without light/shadow artifacts.
- Fallback to Cycles Diffuse Color-only pass if EMIT graph construction fails.
- Solid color fallback: If a mesh has no UVs, detects constant base color and
  generates a 1x1 solid PNG albedo, preventing failed exports.
- Slot isolation: Temporarily clears other material slots during bake to eliminate
  Blender's "No active image found in material slot" error.
- Safe environment: Switches scene render engine to Cycles for baking and cleanly
  restores previous engine (EEVEE/Workbench) and bake settings in a `finally` block.
- Automatically wires generated `<proto>__<mat>_albedo.png` into `.model` samplers.


--------------------------------------------------------------------------------
B) reforge/defold_formats.py
--------------------------------------------------------------------------------
OLD (defold-export-for-blender-main):
- Total length: 92 lines.
- `make_model_text_multi`: accepted `List[Tuple[str, str, str]]`. Hardcoded a single
  sampler block per material:
      textures {
        sampler: "tex0"
        texture: "<path>"
      }
- `make_collection_text_grouped_embedded`: generated `.collection` strictly from
  scratch (~30 lines). Completely overwrote the `.collection` file, wiping out any
  manual edits made inside Defold.
- Only supported flat instance lists under a single proto group.
- `scale_along_z` was hardcoded to 0.

NEW (Current):
- Total length: 439 lines (+347 lines of new logic).
- Multi-sampler support: `make_model_text_multi` accepts `List[Tuple[str, str, dict]]`.
  Iterates over the samplers dictionary, outputting multiple `textures { sampler: ... }`
  blocks per material slot.
- Intelligent `.collection` parser & merge engine:
  * `parse_existing_collection(collection_text)`: parses Defold's protobuf-like syntax.
  * Preserves `component_properties` set on instances in the Defold Editor
    (e.g., custom script properties, tint, health, uniforms).
  * Preserves custom `embedded_instances` (manually added game objects, scripts,
    lights, cameras, particle systems created inside Defold).
  * Preserves `collection_instances` (sub-collections referenced in Defold).
  * Preserves existing `scale_along_z` value.
- Sub-collection & group support:
  * `make_collection_text_grouped_embedded` supports `sub_collections` and `group_transforms`.
  * Outputs named sub-groups (`root -> <group_name> -> instances`) alongside
    prototype groups (`root -> <proto> -> instances`).
  * Emits transforms on group embedded instances when group pivots are defined.


--------------------------------------------------------------------------------
C) reforge/export_core.py
--------------------------------------------------------------------------------
OLD (defold-export-for-blender-main):
- Total length: 200 lines.
- Did not read or preserve existing `.collection` files.
- Did not support texture baking.
- Did not support named sub-collection grouping (`defold_group`).
- Did not support group pivot centers.
- Passed single texture string to `.model` generator.

NEW (Current):
- Total length: 435 lines (+235 lines).
- Integrates texture baking:
  * Detects `bake_color_texture` on materials.
  * Ensures texture directories and executes `bake_color_emit_png`.
  * Wires baked texture paths into samplers (`DIFFUSE_TEXTURE` or `tex0`).
- Non-destructive collection pipeline:
  * Before generating the `.collection`, checks if the file exists and parses it
    with `parse_existing_collection`.
  * Injects preserved `component_properties` back into each exported instance.
- Sub-collection grouping & pivot calculation:
  * Groups objects by `defold_group` (or `defold_collection`).
  * Discovers group centers marked with `group_center` or `defold_group_center`.
  * Computes rigid transform matrix of the center object:
      m_rigid = Matrix.Translation(loc) @ rot.to_matrix().to_4x4()
  * Converts child instances to local coordinates relative to the group pivot:
      m_local = m_rigid.inverted() @ obj.matrix_world
  * Exports group transform on the embedded group node in Defold.
- Added `matrix_to_defold_trs(matrix)` for converting arbitrary transformation matrices.

D) reforge/materials.py
--------------------------------------------------------------------------------
OLD (defold-export-for-blender-main):
- Only had `find_basecolor_image_from_material(mat)`.
- Looked strictly at Base Color / Color socket.
- `resolve_defold_material_and_texture_for_material`:
  * Signature: `(settings, mat, abs_textures_dir, textures_dir_project)`
  * Did not accept `obj` (no object-level overrides).
  * Returned `(mat_name, defold_mat_path, defold_tex_path)` tuple with single texture string.
  * No multi-sampler logic, no Defold Illumination awareness.

NEW (Current):
- Added `ensure_material_props(mat)` for automatic initialization of custom properties.
- Refactored image search into generic `find_image_for_principled_input(mat, input_names)`.
- Added dedicated finders:
  * `find_emission_image_from_material` (Emission, Emission Color)
  * `find_specular_image_from_material` (Specular, Specular IOR Level, Roughness)
  * `find_normal_image_from_material` (Normal)
- Added `NORMAL_MAP` node traversal: walks through `ShaderNodeNormalMap` to extract
  the image connected to its "Color" input socket.
- Object-level property overrides:
  * `resolve_defold_material_and_texture_for_material` now accepts `obj`.
  * Checks `obj["defold_material"]` and `obj["defold_texture"]` as fallbacks before
    defaulting to add-on UI settings.
- Native Defold Illumination library integration:
  * Detects `illumination/materials/model.material` in Defold material path.
  * Populates 5 samplers: `DIFFUSE_TEXTURE`, `DATA_TEXTURE`, `LIGHT_TEXTURE`,
    `SPECULAR_TEXTURE`, `NORMAL_TEXTURE`.
  * Uses `/illumination/textures/empty.png` for unlinked slots and `/builtins/...` logo fallback.
- Returns `Tuple[str, str, dict]` containing full sampler dictionary.

E) reforge/operators.py
--------------------------------------------------------------------------------
OLD (defold-export-for-blender-main):
- `Set Props` operators set prototype name directly from `obj.name`.
- Did not handle duplicates (`.001`, `.002`).
- Did not set `defold_group` or `defold_group_center`.
- `Safe Clear` operators only removed 6 basic keys:
  Object: `defold_prototype`, `defold_collision`, `collision_group`, `collision_mask`

NEW (Current):

  * Added `compute_prototype_name(obj_name, detect_duplicates)` with regex `_DUPLICATE_SUFFIX_RE`.
  * Automatically strips numeric suffixes (`Prop.001` -> `Prop`).
- Extended `Set Props` operators:
  * Sets `defold_group` (with `overwrite_group` toggle).
  * Sets `defold_group_center` (with `overwrite_group_center` toggle).
  * Automatically calls `ensure_material_props` on all materials assigned to objects.
  * Extended status report: reports counts for proto, col, grp, msk, dgrp, and cntr.
- Extended `Safe Clear` operators:
  * Safely removes all new object keys: `defold_group`, `defold_collection`,
    `defold_group_center`, `group_center`.
  * Safely removes all new material keys: `bake_color_texture`, `bake_resolution`,
    `bake_padding`.

G) reforge/utils.py
--------------------------------------------------------------------------------
OLD (defold-export-for-blender-main):
- `export_glb_selected(abs_path: str)`: exported GLB with whatever world transform
  the object currently had in the scene.
- BUG: Blender's glTF exporter with `export_apply=True` preserved world position offsets
  in the GLB node, causing double-transform offsets when instantiated in Defold.

NEW (Current):
- `export_glb_selected(abs_path: str, obj)`:
  * Saves `orig_matrix = obj.matrix_world.copy()`.
  * Snaps object to world origin (`obj.matrix_world = Matrix()`) before glTF export.
  * Silently restores `obj.matrix_world = orig_matrix` in a `finally` block.
  * Guarantees that exported `.glb` mesh data is centered at origin with zero offset.

================================================================================
3. SUMMARY OF BEHAVIORAL CHANGES
================================================================================

1. Collection File Handling:
   - OLD: Overwrote `.collection` completely.
   - NEW: Intelligently parses and preserves Defold components, scripts, embedded
          instances, and collection instances.

2. Complex Shader Support:
   - OLD: None. Only direct Image Texture nodes to Base Color.
   - NEW: Full baking pipeline supporting Ucupaint, procedural nodes, vertex colors,
          and solid color fallback for no-UV meshes.

3. Material Models:
   - OLD: Single sampler `tex0`.
   - NEW: Arbitrary multi-sampler dictionaries with native Defold Illumination 5-sampler
          mapping (Diffuse, Data, Light, Specular, Normal).

4. Cloned Objects / Duplicates:
   - OLD: `Rock.001`, `Rock.002` created separate prototype assets.
   - NEW: `detect_duplicates` maps clones to base prototype `Rock`, sharing assets.

5. Hierarchy & Pivots:
   - OLD: Flat prototype groups only (`root -> <proto> -> instances`).
   - NEW: Sub-collection grouping (`defold_group`) and group pivot centers (`group_center`).

6. Asset Transforms:
   - OLD: GLB could contain world position offsets.
   - NEW: GLB is always cleanly centered at origin via temporary matrix snapping.
