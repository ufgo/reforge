================================================================================
REFORGE - CHANGELOG
Blender to Defold Exporter Add-on & Extension
================================================================================

All notable changes to this project will be documented in this file.


================================================================================
Version 0.6.0
================================================================================

What's New:
-----------
- Texture Baking Pipeline:
  * In-engine color texture baking via Cycles unlit EMIT pass.
  * Full support for complex node setups, including Ucupaint layered textures,
    procedural shaders (Noise, Voronoi, ColorRamp), and vertex colors.
  * Solid color fallback: automatically generates a 1x1 solid PNG for meshes
    without UV unwrapping if a constant color is detected.
  * Per-material bake settings (enable/disable, resolution 512-4096, padding margin).
  * Safe environment isolation: automatically switches scene engine to Cycles
    for baking and restores previous render engine and bake settings afterwards.
  * Material slot isolation: prevents "No active image found" errors from unused slots.

- Multi-Sampler Materials & Defold Illumination:
  * Added multi-sampler texture support to `.model` export.
  * Native integration with Astrochili's Defold Illumination forward-shading library:
    automatically extracts and maps all 5 samplers (DIFFUSE_TEXTURE, DATA_TEXTURE,
    LIGHT_TEXTURE, SPECULAR_TEXTURE, NORMAL_TEXTURE).
  * Intelligent Principled BSDF node traversal, including support for ShaderNodeNormalMap.
  * Automatic assignment of `/illumination/textures/empty.png` to unlinked slots.

- Non-Destructive Scene Re-exports:
  * Re-exporting a `.collection` now parses and preserves existing Defold scene data.
  * Retains instance `component_properties` (script properties, uniforms, tint) set in Defold.
  * Retains custom `embedded_instances` (lights, cameras, custom GOs, scripts) created in Defold.
  * Retains `collection_instances` (referenced sub-collections) and `scale_along_z` settings.

- Sub-Collections & Group Pivots:
  * Support for `defold_group` custom property to organize objects into named
    embedded groups in Defold (`root -> <group_name> -> instances`).
  * Support for `group_center` / `defold_group_center`: calculates rigid transform
    for the group pivot and exports child instances with relative local transforms.

- Prototype Duplicate Detection:
  * Added "Detect duplicates" option in Tools panel: automatically maps numeric Blender
    clones (`Rock.001`, `Rock.002`) to the base prototype (`Rock`).
  * Duplicates share a single `.glb`, `.model`, and `.go` asset while keeping unique
    world transforms in `.collection`, drastically reducing disk space and build size.

- Dedicated Material UI:
  * Added Reforge panel in Blender's Material tab (Properties -> Material -> Reforge).
  * Direct configuration for Defold Material path, Defold Texture path, and texture
    baking options (toggle, resolution, padding).

- Object-Level Overrides:
  * Support for `defold_material` and `defold_texture` custom properties directly on
    mesh objects, overriding material defaults per object.


Fixes & Improvements:
---------------------
- Fix GLB Transform Offsets:
  * Prototypes are temporarily snapped to the world origin `(0, 0, 0)` during `.glb` export
    and restored afterwards, eliminating double-transformation offsets in Defold instances.
- Optimization & Asset Size:
  * Disabled animation export (`export_animations=False`) for static prototypes to reduce GLB file size.
  * External texture export: textures are saved to `assets/textures/` rather than being
    redundantly packed inside binary GLB containers.
  * Duplicate textures are overwritten by filename, preventing `_1.png`, `_2.png` duplicates.
- Extended Tools & Safe Clear:
  * Updated "Set Props" operators to handle sub-groups, group pivots, and duplicate detection.
  * Updated "Clear Export Props" operators with confirmation dialogs to safely remove
    all exporter-created object and material properties without affecting user data.


================================================================================
Version 0.5.2
================================================================================

- Migrated to the modern Blender 4.2+ Extensions platform (`blender_manifest.toml`).
- Added support for one-click installation and automatic updates via Blender Extensions.
- Updated license to GPL-3.0-or-later.
- Minimum supported Blender version set to 4.2.0.


================================================================================
Version 0.5.1
================================================================================

- Initial public release of Reforge (Defold Scene Exporter):
  * Scene export to Defold `.collection` format with matching transforms.
  * Prototype asset export (`.glb`, `.model`, and `.go` prefabs).
  * Prefab protection: `.go` files created once, never overwritten.
  * Basic multi-material `.model` generation with `tex0` sampler.
  * Convex collision export (`.convexshape` and `.collisionobject`).
  * Texture export to `assets/textures/`.
  * Safe cleanup tools for exporter custom properties.
